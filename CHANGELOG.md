# Changelog

## 0.2.0 - 2026-11-13

- Added Google News RSS topic discovery with transient caching.
- Added editorial tone, target article length and focus keyword controls.
- Added suggested SEO title and meta description post metadata.
- Added optional Pexels featured-image search and media import with attribution metadata.
- Added editorial calendar view for drafts and future-scheduled posts.
- Added optional editor-selected future scheduling; generated content remains a draft by default.
- Added provider and Pexels settings screens.
- Improved API key field handling so blank settings submissions retain existing keys.

## 0.1.0 - 2026-11-13

- Initial public development scaffold.
- Added WordPress admin settings for an OpenAI-compatible endpoint.
- Added topic-to-draft generation.
- Added capability checks, nonce verification, sanitization, and output escaping.
- Added a PHP syntax-check GitHub Actions workflow.
