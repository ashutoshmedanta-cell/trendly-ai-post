# Contributing

Thanks for considering a contribution to Trendly AI Post.

## Before you start

- Search existing issues before opening a new one.
- For substantial changes, open an issue first to discuss the approach.
- Never include API keys, credentials, private customer data, or production database exports.

## Development guidelines

- Follow WordPress PHP coding conventions.
- Keep changes focused and document user-facing behavior.
- Check permissions and nonces for admin actions.
- Sanitize input and escape output.
- Do not publish generated content automatically without an explicit, documented opt-in.

## Pull requests

Include:
1. The problem being solved.
2. A concise summary of the change.
3. Testing performed and WordPress/PHP versions used.
4. Screenshots for admin UI changes, with secrets removed.

## Reporting security issues

Please do not publish exploitable vulnerabilities in public issues. For now, use GitHub's private vulnerability reporting feature if it is enabled on this repository. Otherwise, contact the repository owner privately.
